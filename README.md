# Sports Tribe MVP

A mobile-first sports app with live scores, match details, news feed, and live streaming.

## 🚀 Quick Start

### Option 1: Local Testing (Recommended)

```bash
cd "c:\Users\LEARNEDTECH\OneDrive\Desktop\sports tribe app"
python -m http.server 8000
```

Then open: `http://localhost:8000/index.html`

### Option 2: Deploy to App Creator

Upload all files to your app creator platform and set `index.html` as the entry point.

## ⚠️ Important

**Do NOT open `index.html` directly from file explorer** - APIs will be blocked by CORS. Always use an HTTP server or app creator.

## 📱 Features

1. **Live Scores** 🏆 - Today's matches with auto-refresh
2. **Match Details** ⚽ - Comprehensive match info
3. **News Feed** 📰 - Latest football news
4. **Live Stream** 📺 - Embedded video stream

## 🎨 Tech Stack

- Vanilla HTML/CSS/JavaScript
- football-data.org API (Live scores & match details)
- NewsAPI (Sports news)
- Bebas Neue font
